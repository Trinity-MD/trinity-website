Case de Engenharia Corporativa / Logística Crítica

Transporta

🟢 Operação em Produção · Migração V1 → V2 Concluída

A evolução de um ecossistema logístico em produção: da arquitetura inicial à reconstrução cirúrgica da API, modernização do Dashboard Web em Vue 3 e aplicativo Android nativo Kotlin com sincronização offline, conciliação fiscal e migração sem big bang.

Stack V2

Kotlin (Offline-First) · Vue 3 + Vite · TypeScript / Fastify · MongoDB 7.0 · Redis · Oracle Cloud (OCI) · Docker · NS Docs

Cronologia do Projeto

V1 em Produção (Mai/2025 – Jun/2026) · Arquitetura V2 e Cutover (Out/2026)

O Desafio Operacional

Conectar a boleia do caminhão sem sinal à conciliação fiscal na matriz.

Em rotas de carga pesada, motoristas atravessam rodovias sem qualquer cobertura móvel. Registrar canhotos, ocorrências e entregas dependia de formulários manuais ou esperas de dias até o retorno à base, atrasando faturamentos e conciliações fiscais.

O desafio era duplo: criar uma aplicação Android que operasse 100% offline com persistência durável no aparelho e, no backend, automatizar o cruzamento fiscal de CT-e e NF-e com segurança de ponta a ponta.

Solução e Arquitetura

A Tríade V2: Três camadas autônomas, uma operação contínua.

Aplicativo móvel, painel administrativo e API corporativa integrados para garantir resiliência no campo e visibilidade na gestão.

Aplicativo Android Nativo (Kotlin)

Aplicação nativa com arquitetura Offline-First e Outbox Pattern. Motoristas registram viagens, canhotos e ocorrências sem conexão; os dados são assinados com chave local P-256 no Keystore do Android e sincronizados automaticamente com a API, com In-App Updates imediato para blindar a compatibilidade da frota.

Kotlin · Jetpack Compose · Room · Keystore P-256 · In-App Updates

Dashboard Web Administrativo (Vue 3)

Interface de comando operacional reconstruída em Vue 3, Vite e TypeScript. Despacho de cargas, rastreamento de viagens, sinalizadores globais em tempo real e tempo de resposta de consultas otimizado de 13,8s para 1,2s.

Vue 3 · Vite · TypeScript · Tailwind CSS · TanStack Query

API V2 & Conciliação Fiscal (TypeScript + Redis)

Backend enxugado de 139 rotas legadas para 32 contratos cirúrgicos. Autenticação por sessão real e RBAC no servidor, cache Redis e integração assíncrona com NS Docs para leitura automática de XMLs de NF-e e CT-e.

Node.js · Fastify · Redis · MongoDB 7.0 · NS Docs

Infraestrutura Corporativa (Oracle Cloud + Docker)

Ambiente isolado em nuvem corporativa Oracle Cloud (OCI), com contêineres Docker, esteiras independentes de CI/CD para API e Dashboard, proteção Cloudflare Tunnel e isolamento rigoroso de dados.

Oracle Cloud (OCI) · Docker · Cloudflare Tunnel · CI/CD

Engenharia Real

Decisões técnicas fundamentadas em produção.

Diferente de projetos acadêmicos, a evolução do Transporta foi guiada por auditorias rigorosas, contenção de riscos e operação real contínua.

Redução de Superfície: De 139 para 32 Endpoints

A V1 antiga acumulou código inflado. Em vez de portar complexidade desnecessária, auditamos a operação e redesenhamos a API para apenas 32 contratos cirúrgicos, diminuindo drasticamente a superfície de ataque e o custo de manutenção.

Offline-First Real e Grant Durável P-256

Uma resposta 401 de token expirado não apaga a identidade do motorista no meio da estrada. A autenticação local utiliza chaves P-256 no Android Keystore com Fila Outbox durável, desacoplando o trabalho de campo da conectividade de rede.

Migração Sem Big Bang & Idempotência de Dados

A transição entre V1 e V2 operou em coexistência planejada. O ensaio de migração foi validado interrompendo o processo após 4.000 gravações e retomando com mapeamento de UUIDs sem gerar duplicatas ou perder um único registro histórico.

Otimização de Latência: De 13,8s para 1,2s

A reconstrução do Dashboard em Vue 3 eliminou requisições em cascata e gargalos no banco. O tempo de consulta e filtragem de viagens caiu em mais de 90%, garantindo respostas quase instantâneas para os operadores de logística.

Marcos de Evolução

Da validação inicial à consolidação corporativa.

O projeto nasceu como MVP em maio de 2025, foi validado em campo e entrou em produção. Conforme o volume aumentou, a Trinity planejou e executou a refatoração integral para a arquitetura V2, concluída em outubro de 2026 com zero interrupção operacional.
