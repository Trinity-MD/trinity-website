Case / Sistema corporativo

Transporta

Em produção · Projeto privado

Sistema corporativo desenvolvido para digitalizar e centralizar uma operação logística, conectando aplicativo Android, painel web, API, dados e infraestrutura de produção.

Stack

Kotlin · React · Node.js / LoopBack 4 · MongoDB · Docker · Linux

Cronologia

Iniciado mai/2025 · Entregue nov/2025 · Produção jun/2026

Problema

Uma operação que precisava conectar campo e gestão.

O trabalho em campo dependia de documentos e registros conduzidos em processos manuais. Para acompanhar a operação, a gestão precisava reunir essas informações em um fluxo centralizado.

O desafio era ligar a rotina dos motoristas ao acompanhamento administrativo, mantendo os dados disponíveis para consulta e continuidade do trabalho.

Solução e produto

Quatro frentes, uma operação integrada.

Aplicativo, painel, API e infraestrutura cumprem funções distintas dentro do mesmo sistema.

Aplicativo Android

Aplicação nativa em Kotlin para a rotina móvel. Registra dados e documentos, lê códigos e permite continuar o trabalho sem conexão, com sincronização posterior pela API.

Kotlin

Dashboard web

Interface administrativa para cadastros, acompanhamento de registros, filtros e exportações. Concentra a visão da gestão sobre as informações recebidas do campo.

React · Vite · Tailwind CSS

API

Camada em Node.js e LoopBack 4 para comunicação entre aplicativo, painel e banco. Centraliza regras de negócio, autenticação e permissões por perfil.

Node.js · LoopBack 4 · MongoDB

Infraestrutura

Ambiente em Linux com serviços organizados em containers Docker para publicação e operação do sistema em produção.

Docker · Linux

Decisões técnicas

Escolhas ligadas ao uso real.

A arquitetura acompanha a rotina de campo, a necessidade de controle administrativo e a operação contínua do sistema.

Continuidade no campo

O aplicativo mantém dados de trabalho localmente para apoiar o uso sem rede e envia registros pendentes quando a conexão está disponível.

Separação entre interfaces e regras

Aplicativo e dashboard têm fluxos próprios; a API centraliza as regras de negócio e a comunicação com o MongoDB.

Acesso por perfil

Autenticação e permissões diferenciam as ações disponíveis para os usuários do sistema.

Registros consultáveis

A captura de códigos e documentos alimenta os registros da operação; no painel, filtros e exportações apoiam a consulta administrativa.

Estado atual

Em produção, com acesso privado.

O desenvolvimento começou em maio de 2025 e foi entregue em novembro de 2025. A entrada em produção ocorreu em junho de 2026. O sistema atende a uma operação corporativa privada e não possui demonstração pública do ambiente real.
